# ADR 003 — Split du  dataset initial

- **Date** : 2026-10-03
- **Concerne** :  docs/0011__OLTP/05_split.sql, data/*


## Origines du dataset et transformation initiale de colonnes

Le dataset est un fichier csv.
Source : https://aquatic-ursula.s3.eu-central-1.amazonaws.com/stripe/raw/transactions_all.csv

La colonne merchant commence par 'fraud_' pour chacun des merchants. On supprime ce préfixe avec duckdb.

    `duckdb -c "COPY (SELECT * REPLACE (regexp_replace(merchant, '^fraud_', '') AS merchant) FROM 'transactions_all.csv') TO 'transactions_tmp.csv' (HEADER, DELIMITER ',');" && mv transactions_tmp.csv transactions_all.csv`


## Création des fichiers sources pour le projet

 Le dataset est découpé rangé par date, avec duckcdb.
    
- split du csv initial -> Pool de données de remplissage de la base < DATE_COUPURE

    COPY (SELECT * FROM 'data/raw/transactions_all.csv' WHERE CAST(trans_date_trans_time AS TIMESTAMP) < TIMESTAMP '2020-12-12 00:00:00') TO 'data/split/transactions.csv' (HEADER, DELIMITER ',');

- split du csv initial + exclusion de la colonne is_fraud -> réserve pour le pool de transactions fictives pour la simulation des conditions de prod > DATE_COUPURE

    COPY (SELECT * EXCLUDE (is_fraud) FROM 'data/raw/transactions_all.csv' WHERE CAST(trans_date_trans_time AS TIMESTAMP) >= TIMESTAMP '2020-12-12 00:00:00') TO 'data/split/feed.csv' (HEADER, DELIMITER ',');

    COPY (SELECT trans_num, is_fraud FROM 'data/raw/transactions_all.csv' WHERE CAST(trans_date_trans_time AS TIMESTAMP) >= TIMESTAMP '2020-12-12 00:00:00') TO 'data/split/transactions_status.csv' (HEADER, DELIMITER ',');
